# Mohamed Aiman — Full-Stack Developer

I’m Mohamed Aiman (Darkguyaiman), a developer based in Malaysia building web applications with TypeScript, Next.js, React, Node.js, Express, EJS, and MySQL.

**[Explore my portfolio, projects, and contact details → darkguyaiman.com](https://darkguyaiman.com/)**
